    **Step 2: Create internal/walk/walk.go**
    New package `walk` with:
    - `Options` struct: Root (string), MaxDepth (int), Exclude ([]string -- base names to skip), ExcludeAbs ([]string -- absolute path prefixes to skip), OnDir (func(path string, d fs.DirEntry, depth int) bool -- return false to skip descent)
    - `Walk(opts Options) error` function using filepath.WalkDir:
      - Skip non-directory entries
      - Calculate depth relative to Root
      - Enforce MaxDepth (return fs.SkipDir if exceeded)
      - Skip dotfile directories (name starts with ".") at depth 1 ONLY. At deeper depths, allow them (so .build and .venv inside project dirs are discoverable). Exception: always skip ".git" at any depth via the Exclude list.
      - Check ExcludeAbs prefixes
      - Check Exclude base names
      - Call OnDir callback; if it returns false, return fs.SkipDir
      - On permission errors (err != nil), return nil to continue walking
    - Important: The walker is generic and reusable. It does NOT know about project types.
    - Handle symlinks: filepath.WalkDir does NOT follow symlinks by default -- this is correct. Do not change this behavior.

    - TestExcludeByAbsPath: create dirs, verify ExcludeAbs prevents descent
    - TestDotfileDirs: at depth 1 (home level), dotfile dirs are skipped; at depth 2+, .build is visited

    **Step 4: Create pkg/projects/scanner.go**
    New package `projects` with:
    - `projectType` struct: CategoryID, CacheDirName, Markers []string, MarkerInside bool, Label string
    - `projectTypes` slice defining all 5 types (per CONTEXT.md decisions -- node, swift, rust, python with both venv/.venv, java)
    - `Scan() ([]scan.CategoryResult, error)` function:
      1. Get home dir via os.UserHomeDir()
      2. Build a lookup map: cacheDirName -> []projectType (for O(1) matching in callback)
      3. Create walk.Options with Root=home, MaxDepth=5, Exclude=[".git"], ExcludeAbs=[home+"/Library", home+"/Applications"]
      4. In OnDir callback: check if dir name matches a cache dir name in the lookup map. If yes:
         a. Validate manifest marker (sibling or inside depending on MarkerInside)
         b. If valid: get size via scan.DirSize(), get manifest mtime via os.Stat(), parse project name from manifest (fall back to parent dir name), create ScanEntry with path=cache dir, description=project name + age annotation
         c. Return false (don't descend into cache dir)
         d. Also return false for ALL known cache dir names even without manifest (to avoid walking into random node_modules/target/build dirs)
      5. After walk: for each project type with entries, sort entries by size descending, build CategoryResult with aggregate description "label (N dirs, X.X size)", call SetRiskLevels(safety.RiskForCategory)
      6. Return all non-empty CategoryResults
    - `hasManifest(dir string, markers []string) (string, bool)` -- check if any marker file exists, return its path
    - `projectNameFromManifest(manifestPath string) string` -- parse name from package.json (JSON unmarshal), Cargo.toml (line-by-line parse for `name = "..."`), Package.swift (regex for `name: "..."`). Fall back to "" (caller uses parent dir name).
    - `formatAge(mtime time.Time) string` -- <1d: "<1d", <30d: "Xd", <12mo: "Xmo", >=12mo: "Xy"
    - `isStale(mtime time.Time) bool` -- time.Since(mtime) > 180*24*time.Hour
    - Age annotation in description: stale = "project-name  \u26a0 14mo", recent = "project-name  2d"
