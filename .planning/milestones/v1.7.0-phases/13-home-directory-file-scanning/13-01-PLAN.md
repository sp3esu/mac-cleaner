<feature>
  <name>Walk OnFile extension and home directory file scanner</name>
  <files>internal/walk/walk.go, internal/walk/walk_test.go, pkg/homedir/scanner.go, pkg/homedir/scanner_test.go, internal/safety/risk.go, internal/safety/risk_test.go</files>
  <behavior>
    Walk OnFile callback:
    - OnFile is called for each regular file when set; when nil, files are skipped (backward compatible)
    - OnFile receives correct depth relative to root
    - OnFile respects MaxDepth -- files beyond MaxDepth are not reported
    - OnFile files in excluded directories (by name or abs path) are not reported
    - OnFile skips directories that are dotfiles at depth 1 (existing behavior preserved)

    Home directory scanner:
    - Files >= 100MB appear in "home-large-files" category with size
    - Files >= 180 days old AND >= 10MB appear in "home-old-files" category with age annotation in Description
    - A 200MB file from 2 years ago appears in BOTH categories
    - ~/Library, ~/Applications, ~/.Trash, ~/Downloads excluded via ExcludeAbs
    - Dotfile directories at depth 1 excluded (walk default)
    - Project cache dirs (node_modules, .build, target, build, venv, .venv) excluded by name
    - Symlink files are skipped (d.Type()&fs.ModeSymlink != 0)
    - Large files sorted by size descending
    - Old files sorted by size descending
    - Category descriptions show count and total size (e.g., "Large Files >100 MB (3 files, 450.0 MB)")
    - Empty results: no CategoryResult returned for category with zero matches
    - Risk level for both categories is "risky"

    Safety risk entries:
    - RiskForCategory("home-large-files") returns RiskRisky
    - RiskForCategory("home-old-files") returns RiskRisky
  </behavior>
  <implementation>
    1. Add `OnFile func(path string, d fs.DirEntry, depth int)` to walk.Options struct.

    2. In Walk(), replace the `if !d.IsDir() { return nil }` block (line 53) with:
       ```go
       if !d.IsDir() {
           if opts.OnFile != nil {
               depth := 0
               if len(path) > rootLen {
                   rel := path[rootLen+1:]
                   depth = strings.Count(rel, string(filepath.Separator)) + 1
               }
               if opts.MaxDepth == 0 || depth <= opts.MaxDepth {
                   opts.OnFile(path, d, depth)
               }
           }
           return nil
       }
       ```
       Note: The file depth calculation must happen BEFORE the exclusion checks (which only run for dirs). Files inherit their parent directory's exclusion -- if a dir is excluded, WalkDir never descends so files inside are never seen.

    3. Add walk_test.go tests: TestOnFileCallback (files reported with correct depth), TestOnFileMaxDepth (files beyond depth excluded), TestOnFileExclusions (files in excluded dirs not seen), TestOnFileNilBackwardCompat (nil OnFile = no file callbacks).

    4. Add risk entries in internal/safety/risk.go: "home-large-files": RiskRisky, "home-old-files": RiskRisky. Add corresponding test cases in risk_test.go.

    5. Create pkg/homedir/scanner.go with:
       - Package doc comment
       - Constants: defaultSizeThreshold = 100 * 1024 * 1024, defaultAgeThreshold = 180 * 24 * time.Hour, defaultOldFileMinSize = 10 * 1024 * 1024
       - Scan() calls scanFrom(os.UserHomeDir())
       - scanFrom(root) uses walk.Walk with OnFile callback, ExcludeAbs for Library/Applications/.Trash/Downloads, Exclude for project cache dir names, MaxDepth 5
       - OnFile: skip symlinks (d.Type()&fs.ModeSymlink != 0), call d.Info() for size/mtime, check size >= 100MB for large, check age >= 180 days AND size >= 10MB for old
       - Sort both slices by size descending
       - Build CategoryResult with aggregate description, call SetRiskLevels
       - formatAge(mtime) duplicated from pkg/projects (trivial, avoids import cycle)

    6. Create pkg/homedir/scanner_test.go with t.TempDir() filesystem fixtures:
       - TestLargeFiles: create 150MB file, verify in home-large-files
       - TestOldFiles: create 15MB file with old mtime (os.Chtimes), verify in home-old-files with age annotation
       - TestExclusions: create large files inside Library/, Applications/, .Trash/, Downloads/ subdirs, verify NOT in results
       - TestSymlinkSkip: create symlink to large file, verify NOT reported
       - TestDualCategory: create 200MB old file, verify appears in both categories
       - TestOldFileMinSize: create 5KB old file, verify NOT in home-old-files (below 10MB threshold)
       - TestEmptyResults: scan empty dir, verify empty slice returned
       - TestSortOrder: create multiple large files, verify sorted by size descending
